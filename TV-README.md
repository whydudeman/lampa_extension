# EN Online TV — отдельная копия для проверки на LG webOS

Исходный `plugin/en_online.js` не изменён. Новый файл — `plugin/en_online_tv.js`, отдельная кнопка **EN Online TV**, настройки `en_online_tv_*`, API `window.EnOnlineTV.registerProvider(...)`. Можно загружать оба плагина одновременно.

## Установка

Опубликуйте новый файл на том же HTTPS-хостинге, где размещён исходный плагин. В Лампе → Расширения добавьте его фактический URL, заканчивающийся `/plugin/en_online_tv.js`, и перезапустите приложение. Файл пока только создан локально: публикация не выполнялась, готового URL установки нет.

Откройте карточку → EN Online TV → VixSrc. Для сериала выберите сезон и серию. Адрес зеркал необязателен: встроенные домены работают без обращения к фиктивному GitHub USER.

## Результат сетевой проверки 30 сентября 2026

VixSrc прошёл API → embed → главный HLS → вариант → первый фрагмент → ключ AES-128 на фильмах TMDB 550, 680 и серии 1399/1/1. На фильмах проверены оба сервера с Origin `https://lampa.mx` и без него. Это проверка доступности короткой цепочки, не длительного воспроизведения и не физического LG TV.

API VixSrc не возвращает Access-Control-Allow-Origin. Если запросы вашей сборки Лампы выполняются как обычные браузерные запросы, нужен **API proxy**. Поддержка `Lampa.Reguest.native` сама по себе не доказывает обход CORS. Не вводите адрес случайного публичного прокси: нужен реально работающий HTTPS-сервис с известным контрактом `PREFIX/https://target/...`, разрешающий CORS для приложения и возвращающий исходные JSON/HTML. Прокси в эту поставку не включён и не развёрнут.

VidRift отмечен experimental: TMDB 550 прошёл без Origin, TMDB 680 получил 403 на фрагменте; для серии 1399/1/1 потоков не получено. С Origin Лампы плейлисты фильмов получили 403. Простая смена источника или домена этого не исправляет.

## API proxy и HLS proxy — разные настройки

API proxy применяется к запросам API и HTML-страниц. HLS proxy применяется к адресу видео, качествам и внешним субтитрам, передаваемым плееру. Пустые поля означают прямое подключение.

HLS-сервис обязан обрабатывать всю цепочку: главный и вложенные плейлисты, относительные и абсолютные ссылки, URI ключей, EXT-X-MAP, аудио, субтитры и фрагменты; поддерживать Range/206, корректные типы ответов, CORS, HTTPS, таймауты и ограничение разрешённых доменов. Префикс перед одним m3u8 не решает эти задачи. Удаление Origin иногда меняет результат, но не исправляет недоступные фрагменты или серверные отказы. Подмена Referer и обход защиты в рамках сохранённого правила не реализованы.

Не сохраняйте подписанные URL надолго: каждый запуск должен получать свежие токены. На webOS сначала проверяйте H.264/AAC 720p, затем 1080p; точная поддержка зависит от версии телевизора. [Официальные ограничения HLS LG](https://webostv.developer.lge.com/develop/specifications/streaming-protocol-drm).

## Изменения копии

- Отдельные идентификаторы, кэши, настройки и кнопка.
- VixSrc первым; VidRift помечен экспериментальным.
- Зеркало запоминается после получения потоков; при ошибке получения пробуется следующее. Это не автоматическое восстановление после ошибки уже запущенного видео.
- Отмена загрузки подавляет поздние ответы; отдельный сетевой объект на разрешение источника.
- Ошибочный JSON не приводит к необработанному исключению; проверяется наличие токена VixSrc.
- Исправлены URL вида `//host/...`, кодирование токенов и разбор массива streams без обязательного перевода строки.
- Разделены настройки API/HLS-прокси.

## Проверка на настоящем TV

1. Запустить VixSrc, фильм и серию; проверить звук, субтитры и перемотку.
2. Оставить воспроизведение хотя бы на 20–30 минут и повторить на следующий день.
3. При ошибке до списка серверов проверить API/CORS; после выбора сервера — HLS, сегменты и кодеки.
4. Проверить кнопку «Назад» во время загрузки и совместную установку исходного плагина.

Успешное выполнение этих шагов на вашем LG ещё не проверено. Ни один источник здесь не объявлен гарантированно стабильным.

## Воспроизведение локальных проверок

`node scripts/test-en-online-tv.cjs plugin/en_online_tv.js` — независимость копии, резервные зеркала, отмена, маршрутизация прокси и ошибочный JSON.

`python3 scripts/audit-en-online-tv.py` — два раунда проверки 37 адресов, без Origin и с Origin Лампы; результаты по умолчанию в системной временной папке. Это HTTP-опрос, а не эмулятор webOS. Временные body-файлы могут содержать выданные сервером токены; не публикуйте их.

Сводка по каждому адресу — `research/tv-audit/REPORT.md`, обезличенные результаты — JSON рядом.
