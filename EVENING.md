# Вечерний запуск на LG webOS

Подготовлена версия EN Online TV 0.3.0 с небольшим локальным помощником для VixSrc. Он передаёт только API/HTML; видео и звук телевизор получает непосредственно с CDN.

## Запуск

На Mac из папки проекта:

```sh
node scripts/tv-helper.mjs
```

Помощник напечатает адрес установки, например `http://192.168.0.14:8787/en_online_tv.js`. Введите выведенный адрес в Лампе на телевизоре → Настройки → Расширения. Перезапустите Лампу. Выберите фильм → **EN Online TV → VixSrc → Server1**. При сбое попробуйте Server2.

При установке с помощника его адрес подставляется автоматически. В настройках EN Online TV поля API proxy и HLS proxy должны быть пустыми. Ранее установленную версию EN Online TV с другого адреса отключите, чтобы не загружать две версии одновременно. Исходный EN Online можно оставить.

Mac должен оставаться включённым, помощник — запущенным, оба устройства — в одной локальной сети без изоляции клиентов. Адрес Mac может измениться после переподключения. Если macOS запросит доступ Node к локальной сети, разрешите его. Остановить помощник можно Ctrl+C в его терминале.

Если расширение не загружается, откройте корень адреса помощника в браузере телевизора. Если он недоступен — проверьте сеть и firewall. Если доступен, но Лампа запрещает HTTP из HTTPS-страницы, потребуется HTTPS-размещение помощника или совместимая установленная сборка Лампы; это не ошибка извлечения видео. HTTPS-сервер в этой версии не развёрнут.

## Проверено 30 сентября 2026

- «Я, снова я и Ирэн» — TMDB 2123.
- «Властелин колец: Братство кольца» — TMDB 120.
- «Во все тяжкие», сезон 1, серия 1 — TMDB 1396/1/1. Другие серии не проверены.

У всех: API и embed через помощник возвращают 200 с CORS `*`; два сервера отдают HLS; English/eng отмечен DEFAULT=YES; проверены по 1024 байта сегментов видео и английского звука в начале, середине и конце, а также ключи HLS. Это проверка доступности, не прослушивание дорожки, не декодирование полного фильма и не измерение скорости непрерывного воспроизведения. Полный результат: `research/tv-audit/evening-check.json`.

Публичные прокси из оригинального online_mod вернули `Malformed URL` для VixSrc как при прямом префиксе, так и в формате enc2. Поэтому автоматически не используются.

## Ограничения помощника

Допускает только HTTPS-запросы на vixsrc.to к API фильма/серии и embed по числовому ID. Произвольные адреса и редиректы запрещены. Есть таймаут, ограничение размера ответа и количества одновременных запросов. Не публикуйте этот локальный сервис в интернет без дополнительной защиты.

Локальные проверки:

```sh
node scripts/test-en-online-tv.cjs
node scripts/test-tv-helper.mjs
```
